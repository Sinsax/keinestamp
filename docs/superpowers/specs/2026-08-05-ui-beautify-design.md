# Keinestamp UI 美化设计（上白泽慧音双形态主题）

日期：2026-08-05
状态：已获用户批准（"继续"）

## 目标

全新视觉风格：浅色简约风，以上白泽慧音双形态配色为主题。保留现有布局骨架，做少量布局微调，加入适度动画。Logo 一并换色。

## 配色体系（核心）

### 双形态来源色

| 形态 | 主色 | 辅助 | 固定色 |
|---|---|---|---|
| 人形 | 深蓝 | 冰蓝（白发） | 白、正红（领巾/蝴蝶结） |
| 白泽 | 墨绿 | 绿白（白发） | 白、正红 |

### 设计令牌（app.scss :root）

| 令牌 | 值 | 用途 | 来源 |
|---|---|---|---|
| `--accent` | `#D94545` 系（正红） | 主按钮、选中、高亮、标签点缀 | 领巾/蝴蝶结 |
| `--accent-hover` | 正红加深 | 主按钮 hover | 同上 |
| `--primary-blue` | `#2E4A6B` 系（深蓝） | 链接、次要强调、聚焦边框 | 人形 |
| `--ze-green` | `#3E6B52` 系（墨绿） | 部署、成功、白泽元素 | 白泽 |
| `--ice` | `#9FC3E3` 系（冰蓝） | 装饰高光、空状态、标签 | 人形白发 |
| `--bg` | `#F4F6F8` | 应用背景 | 白 |
| `--surface` | `#FFFFFF` | 卡片、面板 | 白 |
| `--surface2` | `#EDF0F4` | hover、次级面 | 浅灰 |
| `--surface3` | `#DCE1E8` | 按压、滚动条 | 浅灰 |
| `--border` | `#E3E7ED` | 细边框 | 浅灰 |
| `--text` | `#1E2833` | 主文字 | 白泽墨色偏蓝 |
| `--text-dim` | `#6B7684` | 次要文字 | 灰 |

| `--error` | `#C94343` 红系 | 错误 | 正红 |

### 语义分配

- 主操作（记录）→ 正红填充白字
- 部署 → 墨绿描边/填充
- 选中/聚焦/链接 → 深蓝 + 正红混合使用（选中边框红、聚焦边框蓝）
- 成功 toast → 墨绿；错误 toast → 正红
- 标签多色保留（建模/UV拆分/绑定/贴图/修复），微调为低饱和同族色，保持与红色主色的和谐

## 视觉语言

- 圆角：卡片 10px、按钮 8px、弹窗 14px、徽章 999px
- 阴影：卡片 `0 1px 2px rgba(30,40,51,0.06)`，hover `0 4px 12px rgba(30,40,51,0.10)`，弹窗 `0 16px 48px rgba(30,40,51,0.18)`
- 边框：1px 极浅 `--border`，选中/焦点换主题色
- 文字层级：字重（600/500/400）+ 字号区分，弱化颜色对比
- 等宽字体：hash、路径、diff 用 `ui-monospace, 'Cascadia Mono', Consolas, monospace`
- 删除生硬色块：所有纯色块改为背景浅染 + 主题色文字

## 布局微调

1. **合并工具栏**：顶部 path 工具栏与底部 ActionBar 之间的冗余按钮（刷新等）收编；顶部工具栏改为纯路径 + 打开文件夹 + 折叠侧栏按钮
2. **时间线面板可拖拽调宽**：默认 320px，范围 240–480px，持久化到 localStorage
3. **侧栏可折叠**：顶部工具栏按钮切换，折叠为 44px 窄条（保留图标提示），状态持久化 localStorage

## 组件细节

### TitleBar
- 背景改 `--surface` 白 + 细底边框；标题前 Logo 换红白配色
- 按钮 hover 红系；关闭按钮 hover 正红填充白字

### Logo（红白）
- 主体改正红，高光线条改白/冰蓝，叶脉改深红；保持原有树枝/花形态

### ProjectTabs
- 标签页改为「胶囊」风格：未选中透明描边，选中白底+红色底边条或红色文字；hover 上移 1px + 过渡
- 新建（+）与设置按钮统一为图标按钮，hover 红系

### Sidebar
- 可折叠窄条（默认展开）；文件树 hover 行背景 + 选中行红色左边条（沿用）
- 退出按钮改红色描边悬停填充

### StatusPanel（Changes）
- 行 hover 白底上浮；状态图标彩色化（A 墨绿 / M 暖金 / D 正红 / ? 灰）
- 扩展名徽章改浅染背景

### EntryList（时间线）
- 卡片白底圆角 10px + 细边框；hover 上浮 + 红色边框；选中红色左边条 3px
- 标签分组：色点 + 标签文字 + 细线；标签徽章圆角胶囊
- 文件状态徽章：+ 墨绿 / − 正红 / ~ 暖金，浅染背景
- Diff：add 墨绿浅染、del 正红浅染、mod 深蓝浅染；行号弱化
- 「3D 模型预览」按钮：红色描边悬停填充
- 访问令牌区：沿用现有交互（单击复制/双击编辑），样式统一为新主题

### ActionBar
- 记录 = 主按钮（正红填充白字，hover 加深 + 上浮）
- 导出/撤回 = 次要按钮（白底描边）
- 部署 = 墨绿描边（connected 时可用）
- 按钮加入微过渡（active 缩放 0.97）

### 弹窗（CommitDialog / SettingsDialog / DetailPanel）
- 遮罩 `rgba(30,40,51,0.35)` + `backdrop-filter: blur(4px)`
- 入场动画 fade + scale(0.96→1)，200ms
- 弹窗白底 14px 圆角 + 大阴影
- 表单 focus 红色边框 + 浅红光晕

### Toast
- 白底 + 左侧色条（success 墨绿 / error 正红 / info 冰蓝）+ 图标
- 滑入 + 3s 后淡出（保留现有逻辑，加淡出动画）

### 空状态
- 冰蓝浅染圆形图标底 + 深色文字，SVG 图标统一

### 滚动条
- 6px 圆角，thumb `--surface3`，hover 深灰

## 动画（适度）

- 全局过渡 150–200ms ease-out；hover 上浮 4px 阴影过渡
- 弹窗入场 fade+scale；卡片/按钮 active 缩放
- 状态点（连接指示）闪烁平滑保留
- 不引入新动画库，纯 CSS

## 不做的（YAGNI）

- 不引入 UI 框架、不重构组件模板逻辑
- 不做暗色模式切换
- 不改任何 Rust 后端 / Tauri 命令
- 不改布局结构（侧栏/主区/时间线三栏不变）

## 技术方案

- 方案 A（已选定）：`app.scss` 令牌重建 + 各 `.svelte` 组件样式局部重写 + `TitleBar.svelte` Logo SVG 换色 + 拖拽调宽/折叠逻辑（纯前端，localStorage 持久化）
- 验证：`cd frontend; npm run check`（svelte-check + tsc）；`cargo tauri dev` 手动目检
- 无 Rust 侧改动，`cargo test` 不需要

## 测试

- 无逻辑改动处不做新测试；新增拖拽/折叠逻辑为纯 UI 状态（localStorage），不做单元测试
- 验证方式：`npm run check` + 视觉目检清单（在实现计划中列出每组件核对项）
